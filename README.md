## NO LONGER MAINTAINED.

# Barrels
A Slimefun Addon which replicates the popular barrels found in modpacks.

> **Unofficial port notice**
> This working copy is an **unofficial port** of the original Barrels addon
> (https://github.com/John000708/Barrels) to **Slimefun United** on **Paper 1.21.4 / Java 21**.
> The original project is no longer maintained; original author John000708 keeps all credit,
> and the original license applies. This port is not affiliated with or endorsed by the original
> author. See [`MIGRATION_NOTES.md`](MIGRATION_NOTES.md) for what changed, known limitations
> and the manual test checklist. Built jar: `dist/Barrels-2.0.0-unofficial.jar`.

Since this is a Slimefun Addon, you will need to install [Slimefun United](https://github.com/Slimefun-United/Slimefun-United)
on Paper 1.21.4 before you can use this Plugin. **CS-CoreLib is no longer required** — all of its
utilities were migrated to Slimefun United / dough as part of this port.
