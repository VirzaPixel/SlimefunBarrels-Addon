# Barrels

A Slimefun addon that adds barrels for bulk item storage.

Built for **Paper 1.21.4 / Java 21** with **Slimefun United**. No CS-CoreLib required.

## Features

- 5 barrel tiers (Small → Deep Storage Unit)
- Structural upgrades (I/II/III) for extra capacity
- Explosion-protection module
- Biometric module + ID card (owner-only access)
- Floating display item above each barrel

## Building

```bash
mvn clean package
```

Requires JDK 21 and a local Slimefun United jar. See `MIGRATION_NOTES.md` for details.

## Installation

1. Install [Slimefun United](https://github.com/Slimefun-United/Slimefun-United) on Paper 1.21.4
2. Drop `Barrels-2.0.0-unofficial.jar` into `plugins/`
3. Restart the server
